Vi ser etter denne profilen for MASENSE i Madrid.

- Stillingsform: Heltid
- Arbeidsform: Kontor / Hybrid
- Lokasjon: Madrid
- Fleksibilitet: Remote og kontor

Ansvar for cloud-backbone bak tilkoblede enheter, fra forste utrulling til stabil produksjonsdrift.

## Beskrivelse

Bygge og overvake containerbaserte tjenester. Hands-on startup-miljo der autonomi og ansvar betyr mer enn hierarki.

## Erfaring

Dokumentert erfaring med design, utrulling og drift av cloud-systemer som samhandler med embedded enheter. Erfaring med produksjonssystemer fra prototyping til skalering og vedlikehold.

## Tekniske ferdigheter

- Solid kunnskap om containerbaserte systemer med Docker.
- Erfaring med a bygge og drifte monitorering og observability-stack (for eksempel Grafana, metrikker og logging).
- God kunnskap om cloud-databaser.
- Erfaring med systemsikkerhet, autentisering, tilgangskontroll og sikker kommunikasjon (MQTT / REST / Modbus) mellom tjenester og enheter.
- Kjennskap til embedded Linux-baserte systemer og nettverksgrunnlag.
- Evne til a integrere cloud-infrastruktur med embedded hardware.
